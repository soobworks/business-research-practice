# 가치사슬 비교 분석: 위치기반 SNS vs. 수소 배터리 전기 승용차

> 개별 분석: [위치기반 SNS](value-chain-analysis-location-sns.md) / [수소 전기 승용차](value-chain-analysis-hydrogen-ev.md)
> 관련 산업구조 분석: [Porter's Five Forces 비교](../porters-five-forces/porters-five-forces-analysis-location-sns-vs-hydrogen-passenger-ev.md)

## 1. 각 산업이 집중 분석한 활동

| 산업 | 심층 분석 활동 | 선정 근거 |
| --- | --- | --- |
| 위치기반 SNS | 투입·조달 물류 / 마케팅 및 영업 / 서비스 | 물리적 원가는 낮고, 위치 데이터의 리스크·차별화와 로컬 확산·신뢰 관리가 성패를 가름 |
| 수소 전기 승용차 | 투입·조달 물류 / 산출·배송 물류 / 기술 개발 | 희소자원 조달과 충전 인프라라는 물리적 제약이 원가·매출을 직접 규정함 |

두 산업 모두 **투입·조달 물류**를 공통 심층 분석 대상으로 선정했다는 점이 눈에 띔 — 다만 그 이유는 완전히 다름(하나는 외부 API 종속, 하나는 희소금속 종속).

## 2. 활동별 비교

| 활동 | 위치기반 SNS | 수소 전기 승용차 |
| --- | --- | --- |
| 투입·조달 물류 | 사용자가 스스로 콘텐츠·위치를 공급 — 조달 대상이 "사람의 행동"이며, 원가보다 지도 API 종속이라는 리스크가 핵심 | 백금 등 희소금속·소수 기술벤더에 물리적으로 의존 — 원가·지정학 리스크가 핵심 |
| 운영·생산 | 콘텐츠 검수·추천 알고리즘 중심, 한계비용 거의 0 | 고압수소 안전인증 등 규제형 공정, 한계비용 높음 |
| 산출·배송 물류 | 디지털 전달, 제약은 네트워크 효과(알림 피로도) 문제 | 물리적 유통, 제약은 인프라(충전소) 부재라는 이 산업 고유의 병목 |
| 마케팅 및 영업 | 로컬 시딩 → 바이럴 확산, 유일한 차별화 지점 | 보조금·플릿 고객 중심, 상품력만으로 소구 어려움 |
| 서비스 | 프라이버시·안전(신고/차단) 대응이 신뢰 리스크 관리의 핵심 | 전문 정비망 부족이 병목, 물리적 A/S 필요 |
| 기술 개발 | 추천 알고리즘, 유해 콘텐츠 탐지 | 백금 저감·연료전지 효율 — 대체재(BEV) 압력에 대응하는 유일한 레버 |

## 3. 핵심 차이: 병목이 위치한 지점

- **SNS의 병목은 가치사슬의 "출구"(마케팅·서비스) 쪽**에 있음 — 콘텐츠를 만들고 전달하는 것 자체는 저비용이지만, 로컬 임계질량을 확산시키고 신뢰(프라이버시·안전)를 유지하는 단계에서 성패가 갈림.
- **수소 전기 승용차의 병목은 가치사슬의 "입구와 중간"(조달·산출물류) 쪽**에 있음 — 희소자원 조달과 충전 인프라라는 물리적 제약이 마케팅·서비스 단계까지 도달하기 전에 이미 사업의 한계를 규정함.
- 이 차이는 두 산업의 근본 성격을 반영함: SNS는 **디지털 네트워크 효과 기반 사업**이라 물리적 제약이 거의 없는 대신 신뢰·확산이라는 무형 자산이 병목이 되고, 수소차는 **물리적 인프라 기반 사업**이라 아무리 마케팅·서비스를 잘해도 조달·인프라 제약을 우회할 수 없음.

## 4. 공통점: 외부 의존이 핵심 리스크

- 두 산업 모두 **핵심 투입자원을 소수 외부 공급자에 의존**함 — SNS는 지도 API(구글맵 등 소수 과점), 수소차는 희소금속·연료전지 스택(소수 벤더).
- 두 산업 모두 **기업 내부 역량만으로는 가치사슬이 완결되지 않음** — SNS는 지도 API 공급사의 정책 변화에, 수소차는 정부의 충전 인프라 투자·보조금 정책에 사업의 지속가능성이 걸려 있음.
- 이는 [Five Forces 분석](../porters-five-forces/porters-five-forces-analysis-location-sns-vs-hydrogen-passenger-ev.md)에서 두 산업 모두 "대체재 위협"이 가장 큰 리스크 축으로 나타난 것과 같은 맥락 — 가치사슬 내부를 아무리 잘 설계해도, 산업 외부 요인(플랫폼 정책, 정부 정책)이 그 설계의 상한을 결정한다는 점에서 두 분석 프레임워크의 결론이 서로를 보강함.

## 5. 전략적 시사점

- **SNS**: 지도 API 종속을 낮추는 기술 투자보다, 로컬 확산 전략과 신뢰(프라이버시) 관리에 조직 역량을 집중하는 것이 우선순위 — 병목이 출구 쪽에 있기 때문.
- **수소 전기 승용차**: 마케팅·서비스 고도화보다, 조달 리스크 완화(백금 저감 R&D)와 충전 인프라 파트너십 확보가 우선순위 — 병목이 입구 쪽에 있어 뒷단을 아무리 개선해도 근본 해결이 안 됨.
- 가치사슬 분석의 실전적 가치는 **"어느 활동에 자원을 우선 투입해야 하는가"를 알려주는 데 있음** — 두 산업은 정반대 지점에 병목이 있어, 동일한 개선 노력(예: 마케팅 강화)도 한쪽에서는 효과적이고 다른 쪽에서는 근본 해결책이 되지 못함.
