# kb-home — 이 프로젝트의 LLM Wiki

`llm-wiki.ko.md`가 설명하는 3계층 패턴(원본 소스 / 위키 / 스키마)을 이 프로젝트에 적용한 인스턴스다.

| 계층 | 이 프로젝트에서의 위치 |
| --- | --- |
| **원본 소스(불변)** | 프로젝트 루트의 `01.porters-five-forces/` ~ `08.competitor-branding/` — 이미 축적된 원본 분석 문서. 새로 들어오는 미분류 원본은 `raw-inbox/`에 임시로 둔다 |
| **위키(LLM 소유)** | `wiki/` — 엔티티·개념·케이스·비교·종합 페이지. `wiki/index.md`·`wiki/log.md`가 카탈로그·연대기 역할을 한다 |
| **스키마** | 아직 작성 전(다음 단계) — 이 위키의 표기 규칙·수집(ingest)/질의(query)/린트(lint) 워크플로우를 정의할 `SCHEMA.md` |
