# 용어 정의

> 여러 케이스·프레임워크에서 반복 등장하는 용어를 모은 페이지. 항목이 늘어나면 용어별 개별 파일로 분리한다.

| 용어 | 정의 | 출처 개념 |
| --- | --- | --- |
| **Market Relevance (MR)** | DOS 계산에서 시장 파급력을 나타내는 계수. 이 프로젝트에서는 Pain별이 아니라 **인물(페르소나)별로** 부여하는 규칙을 확립했다 — Pain별로 매기면 Importance를 두 번 세는 결함이 생긴다 | [market-opportunity-score](../frameworks/market-opportunity-score/index.md) |
| **Pareto 열위 제거** | 다른 옵션보다 모든 축(가격·시간)에서 동시에 나쁜 선택지를 제거하는 방식. 임의 가중치("가격 40%, 시간 30%") 없이 추천을 좁힐 때 쓴다 | [1인가구-한끼라우터](../../cases/1인가구-한끼라우터/index.md) |
| **하이퍼로컬 임계질량** | 전국 단위 승부 대신 특정 로컬 커뮤니티(대학·지역)에서 네트워크 효과가 자생하는 최소 밀도를 먼저 확보하는 전략 | [ksf](../frameworks/ksf/index.md) |
| **top-down / bottom-up 추정** | top-down은 "전체 시장×비중"으로 위에서 쪼개는 방식, bottom-up은 "인구수×단가"로 아래에서 쌓는 방식. 이 프로젝트는 bottom-up을 더 신뢰할 수 있는 근거로 취급한다 | [tam-sam-som](../frameworks/tam-sam-som/index.md) |
| **니치(niche) 해자** | 대기업이 기능을 복제해도 방어되는, 정서적·구조적으로 좁은 포지션(예: Life360의 "가족 안전") | [ksf](../frameworks/ksf/index.md) |
| **JTBD 4 Forces** | Push(현상 불만)·Pull(새 솔루션 매력)·Habit(관성)·Anxiety(불안) — 전환/비전환을 이끄는 네 힘 | [jtbd](../frameworks/jtbd/index.md) |
| **(확인)/(근사)/(추정)/(가정)/(내부기준)** | 이 프로젝트 전체가 쓰는 5단계 근거 등급 표기. 실제 인터뷰 없는 값은 (가정)으로, 다른 모집단에서 유추한 값은 (근사)로 명확히 구분한다 | [1인가구-한끼라우터/value-proposition](../../cases/1인가구-한끼라우터/value-proposition.md) |

## 근거 등급
