# Value Proposition 통합 문서

TAM-SAM-SOM·페르소나·CJM·JTBD·경쟁분석·SRS를 하나의 고객가치 선언과 MVP 우선순위로 잇는 최종 종합 문서 작성법.

## 8개 필수 항목

페르소나/CJM 기반 Pain·Needs → JTBD Goal/Job → 측정 가능한 Outcome → 기존 대안 → 핵심 제안(Value Proposition) → 차별적 가치 → Proof(근거+비교시각화) → Job-Feature Map(MVP 포함여부·우선순위).

## 이 프로젝트가 겪은 두 번의 재구성

1. **v1.0 합본** — 독립적으로 생성된 두 버전(자체 작성본 + 외부 LLM 산출물)을 대조해 장단점을 통합. 마스터 선언의 논리적 필요조건(3기둥)과 확장 가치(4번째 기둥)를 구분해 정직하게 남겼다.
2. **v2.0 rooted** — 다른 챕터 문서로의 링크 참조를 없애고, 모든 근거를 문서 하나에 직접 인용해 자기완결적으로 만든 버전. "1000개 문서로 확장 가능한 위키"([kb-home](../../../../README.md))로 가는 것과 반대 방향(집중·자기완결) 실험이었다는 점에서 대비된다.
