# JTBD (Jobs-To-Be-Done)

"고객이 누구인가"가 아니라 "고객이 어떤 상황에서 어떤 진보를 이루려 하는가"에 초점을 맞추는 방법론. 전환(고용/해고)을 이끄는 **4가지 힘**(Push·Pull·Habit·Anxiety)을 관찰하는 인터뷰 기법과, `When [상황], I want to [동기], so I can [결과]` 형태의 선언 문장이 핵심 산출물이다.

## 페르소나 선언과의 차이

| | 페르소나 선언 | JTBD 선언 |
| --- | --- | --- |
| 형태 | "~로서, 나는 ~해야 한다" | "~할 때, 나는 ~을 원한다" |
| 원인 | 속성(나이·직업) | 상황(맥락) |
| 문제 | 속성은 행동의 원인이 될 수 없다 | 상황이 행동을 유발한다는 것을 드러냄 |

## 인터뷰 대상 선정 — 두 기준의 교집합

이 프로젝트가 확립한 방식: ① 페르소나 스펙트럼의 핵심+확장 그룹만(극단·비활성 제외) ② [AOS×DOS 혼합매트릭스](../market-opportunity-score/index.md)의 최우선+니치마켓 사분면. 두 기준을 교집합하면 인터뷰 대상이 좁혀진다 — [1인가구-한끼라우터 케이스](../../../cases/1인가구-한끼라우터/jtbd.md)에서는 C1·C3·A2 세 명으로 좁혀졌고, 이 과정에서 **C5(Q4 원형 핵심 페르소나)가 누락된 채 시작됐다가 사용자 지적으로 뒤늦게 발견된 이력**이 있다 → [decisions](../../../decisions/index.md), [open-questions](../../../open-questions/index.md) 참고.

## JTBD 기반 vs 페르소나 기반 AOS-DOS

| | 페르소나 기반 | JTBD 기반 |
| --- | --- | --- |
| 데이터 출처 | 가정적 인식 | 실제 인터뷰/행동 관찰 |
| 결과물 | 시장 세분화용 | 제품 기획 우선순위용 |

이 프로젝트의 산출물은 **모의 인터뷰**(AI 생성 응답) 기반이라 아직 "페르소나 기반"과 같은 (가정) 등급에 머문다 — 실제 인터뷰가 끝나야 등급이 (확인)으로 올라간다.
