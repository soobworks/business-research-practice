## KSF 문서에서 재구성한 Five Forces 핵심 결론

| 힘 | 인용된 결론 |
| --- | --- |
| 신규 진입자 위협 | 진짜 장벽은 "생태계 전체가 동시에 갖춰져야 한다"는 것 — 실제 진입 경로는 완성차와 에너지 대기업의 합작 |
| 공급자의 힘 | 백금 촉매가 매우 강함 — 남아공 등 특정 지역 편중, 대체 원료 거의 없어 협상 자체가 성립 안 함 |
| 구매자의 힘 | 정부·공공조달이 "정책이 곧 구매력" — 시장논리가 아니라 정치논리로 움직임 |
| 대체재 위협 | "빠른 충전+장거리"가 유일한 소구점이나 BEV 급속충전·800V 발전으로 격차가 빠르게 좁혀지는 중 |

## KSF Top 5 (기업 사례 포함, 순서는 "완성차 회피"가 전제이므로 1순위로 재배열)

1. 개인 승용차 대신 상용·플릿 세그먼트 우선 공략 — 현대차 넥쏘(정체) vs 엑시언트 수소트럭(유럽 플릿 공급)
2. 완성차-에너지기업 합작을 통한 생태계 동시 구축 — 현대차의 코하이젠 컨소시엄
3. 백금 의존 낮추는 촉매 R&D — 토요타 미라이 2세대
4. BEV 대비 충전시간·주행거리 격차 유지 — 혼다 클래리티(실패 사례, 생산중단)
5. 정부 정책 로드맵과의 선제적 정합 — 토요타의 일본 "수소사회" 국가전략 초기 협력

> 📌 참여 기업 자체가 극소수(현대·토요타·혼다)라 여러 KSF에 같은 기업이 반복 등장 — 이는 조사 한계가 아니라 "신규 진입자 위협 낮음"이라는 Five Forces 진단을 방증한다.
