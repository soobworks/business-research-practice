## KSF 문서에서 재구성한 Five Forces 핵심 결론

| 힘 | 인용된 결론 |
| --- | --- |
| 신규 진입자 위협 | 네트워크 효과가 "로컬로 쪼개져 있다" — 방어자에게 불리 → 전국 단위로 이길 필요 없이 특정 대학·지역만 뚫으면 교두보가 생김. 진짜 위협은 신생 스타트업이 아니라 인접 거인(인스타그램 등)의 기능 복제 |
| 공급자의 힘 | 크리에이터는 여러 플랫폼 동시 운영(멀티호밍)이 기본, 전환비용 사실상 0 — 붙잡으려면 크리에이터 펀드 등으로 비용 지출 필요 |
| 구매자의 힘 | 광고주는 메타·구글·틱톡이라는 대안이 항상 있고 성과(ROAS)로 즉시 비교당하는 매우 강한 구매자 |
| 대체재 위협 | "시간 때우기" 욕구가 가장 치명적 — 가처분 시간 전쟁이라 모든 콘텐츠 산업이 대체재가 됨 |

## KSF Top 5 (기업 사례 포함)

1. 하이퍼로컬 임계질량 우선 확보 — Facebook(하버드→아이비리그), Snapchat(미 고등학생)
2. 대기업 기능 복제 대비 방어 가능한 니치 설계 — Zenly(실패, 위치공유 단일기능) vs [Life360](../../entities/companies/index.md)(성공, "가족 안전" 니치)
3. 크리에이터 멀티호밍 대응 리텐션 투자 — TikTok Creator Fund/Creativity Program
4. 광고 의존 탈피, 로컬 커머스 연동 — 당근마켓(당근비즈니스)
5. "시간 점유" 경쟁 회피, 좁은 니즈 포지셔닝 — Strava(운동기록+크루소셜)
