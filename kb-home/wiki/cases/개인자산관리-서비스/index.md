# 케이스: 금융데이터 기반 개인 맞춤형 자산관리 서비스

> 원본: `01.porters-five-forces/분석③-개인자산관리서비스.md`, `02.value-chain/분석-개인자산관리서비스.md`. 이 케이스는 Five Forces·Value Chain까지만 진행되고 KSF·이후 단계로 심화되지 않았다(연습용 초기 케이스, 최종 채택은 [1인가구-한끼라우터](../1인가구-한끼라우터/index.md)).

## 분석 단위

마이데이터(금융데이터 통합 조회) 기반 개인 자산 현황 분석·맞춤형 자산배분·금융상품 추천 핀테크 플랫폼. 참고 사례: 토스, 뱅크샐러드, 카카오페이. 고객이 무료 조회 이용자와 유료·AUM 고객 두 층으로 나뉘고, 금융위·금감원이 시장 진입 자체를 결정하는 게이트키퍼로 작동한다는 점이 일반 소비재 산업과 다르다.

## Five Forces

| 힘 | 강도 | 핵심 근거 |
| --- | :---: | --- |
| 공급자의 힘 | 매우 높음 | 금융데이터 제공자(은행·카드사)가 **공급자이자 최대 경쟁자**라는 이중 지위 |
| 구매자의 힘 | 높음 | 무료 이용자는 멀티호밍(전환비용 0), 유료 고객은 신뢰 축적으로 다소 낮지만 자문수수료 표준화로 협상력 상승 중 |
| 신규 진입자 위협 | 중간 | 진짜 장벽은 **마이데이터 라이선스라는 인허가제** — 통과 후엔 다시 무방비 경쟁 |
| 대체재 위협 | 중간 | 가장 치명적인 것은 "은행 창구 직접 상담" — 고액자산가일수록 이 경로 선호 |
| 경쟁 강도 | 높음 | 토스·뱅크샐러드·카카오페이 3파전, 무료 조회 기능 동질화로 상품 큐레이션 경쟁으로 수렴 |

**종합**: 산업 매력도 **낮음~중간**(인허가 보호형 과당경쟁). 전략: 특정 세그먼트(사회초년생·은퇴설계) 집중화 권장, 크로스셀이 사실상 유일한 수익원.

## Value Chain

심층분석 3활동: **투입·조달물류**(마이데이터 API — 소유 못하는 원재료, 데이터 제공자가 곧 경쟁자) · **마케팅및영업**(무료→유료 크로스셀 전환이 유일한 수익화 경로) · **서비스**(불완전판매 방지가 핵심 규제 리스크).

> 📌 이 케이스와 [1인가구-한끼라우터](../1인가구-한끼라우터/value-chain.md)는 둘 다 **핵심 투입자원을 소유하지 못한다**(라이더 vs 금융데이터)는 같은 구조를 가진다 — [니치 집중 전략 반복](../../syntheses/니치-집중-전략-반복.md)과는 별개의 교차 패턴 후보, [open-questions](../../open-questions/index.md) 참고.
