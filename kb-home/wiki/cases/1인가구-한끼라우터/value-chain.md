# 1인가구-한끼라우터 — Value Chain

> 원본: `02.value-chain/분석-1인가구배달플랫폼.md` · 개념: [value-chain](../../concepts/frameworks/value-chain/index.md)

심층분석 3활동: **투입·조달물류**(라이더 확보, 멀티호밍으로 "매 순간 재확보"에 가까움) · **산출·배송물류**(배송 자체가 제품의 실체, ETA 정확도가 곧 품질) · **마케팅및영업**(쿠폰이 상시 원가 항목으로 고정, 구독형 정기주문이 유일한 완화책).

**종합**: 라이더(투입)와 배송(산출)이 "사람의 이동"이라는 동일 자원에 의존 — 조달과 산출이 하나의 자원 관리 문제로 수렴한다.
