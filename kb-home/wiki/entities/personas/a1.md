# A1「1인분은 손해다」

> 소속 케이스: [1인가구-한끼라우터](../../cases/1인가구-한끼라우터/index.md) · 유형: 🟢확장(Adjacent) · Q2

| 항목 | 내용 |
| --- | --- |
| 직무 | 대학생·야간 편의점 알바 |
| 문제 | 용돈·알바비로 생활해 예산 민감도가 Core보다 훨씬 높음. 배달앱 최소주문금액 때문에 혼자 시키면 손해라고 느낌 |
| 목표 | 1인분만 시켜도 손해 보지 않는 선택지를 빠르게 찾기 |
| 감정 | 최소주문금액 앞에서 매번 느끼는 억울함 |
| 대체 솔루션 | 알바지 편의점 상품으로 직접 해결 |

## 흥미로운 발견

CJM ⑤단계(수령·준비)에서 오히려 감정 점수가 오른다 — 편의점 채널을 선택한 순간 ③단계의 Pain(최소주문금액)이 자연히 해소되기 때문. **채널 선택 자체가 Pain 회피 전략으로 쓰이는** 유일한 사례.
