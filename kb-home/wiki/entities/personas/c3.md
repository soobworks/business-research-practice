# C3「매일이 곧 지출이다」

> 소속 케이스: [1인가구-한끼라우터](../../cases/1인가구-한끼라우터/index.md) · 유형: 🔵핵심(Core) · Q2(재분류) · JTBD **Primary-2** 인터뷰 대상

| 항목 | 내용 |
| --- | --- |
| 직무 | 제조업 대기업 사무직 |
| 문제 | 정시 퇴근이지만 혼자 사는 집에서 요리할 의욕이 없어 거의 매일 배달·포장에 의존, 누적 지출이 부담 |
| 목표 | 매일 반복되는 지출을 줄이되 매번 새로 고민하지 않기 |
| 감정 | 귀찮음과 지출 부담 사이의 무력감 |
| 대체 솔루션 | 편의점 도시락으로 며칠 버티다 다시 배달로 복귀 |

## CJM 병목

①오늘의갈등(지출 방치)~⑥소비·피드백(사후 인지). 대표 Pain: **P07** 방치될수록 누적 지출이 커진다(AOS 2.4) · **P09** 지출 누적 확인 못 함(AOS 2.4, DOS(SAM) 최상위권).

## JTBD (모의 인터뷰, 가정)

> "퇴근하고 요리할 힘이 하나도 없을 때, 나는 생각 없이 그냥 시키고 싶다. 근데 그러면서도 지출은 늘리고 싶지 않다. 왜냐하면 나중에 카드값 보고 후회하고 싶지 않아서다."

인터뷰에서 P09가 구체적 기능 요구("누적 지출 대시보드")로 좁혀지며 DOS(SAM)이 0.40→0.60으로 상향 재판정(O02). 신규 발굴: **예산 확인 자동화**(O06) — "확인 행위 자체가 새 숙제가 되면 안 된다."
