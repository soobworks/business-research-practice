# C2「마감엔 다 필요없다」

> 소속 케이스: [1인가구-한끼라우터](../../cases/1인가구-한끼라우터/index.md) · 유형: 🔵핵심(Core) · Q4

| 항목 | 내용 |
| --- | --- |
| 직무 | 프리랜서 콘텐츠 마케터 |
| 문제 | 재택근무라 규칙적 식사시간이 없음. 마감 직전엔 가장 빨리 오는 걸 시켜 예산을 초과하고, 그 죄책감이 다음 선택도 흐트러뜨림 |
| 목표 | 마감 기간에도 예산을 지키면서 스트레스 없이 정하기 |
| 감정 | 지출까지 통제 못 한다는 자책감 |
| 대체 솔루션 | 최근 주문 목록에서 고민 없이 재주문 |
