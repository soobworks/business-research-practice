# 5단계 — 정량적 검증 (Quantitative Validation) [재구성]

> ⚠️ **이 파일에 대한 안내**: 사용자가 제공한 3개 docx는 1~4단계, 6단계, 7단계를 담고 있으며 **5단계 원본 문서는 없다**. 다만 [6단계 문서](./06-iterative-refinement.md)가 "1차 시각화 검토 결과" 표에서 5단계가 만든 1차 차트·수치를 그대로 나열하고 있어, 이를 근거로 5단계 산출물을 역으로 재구성했다. 6단계에서 채택/제외/강등 판정을 받기 **이전의 원본 상태**를 보여주는 것이 이 파일의 목적이다.
>
> **AI 역할**: 데이터 시각화 담당
> **핵심 산출물**: 4단계에서 정의한 측정변수(총비용, 총시간, 선택률, WTP 등)를 뒷받침하는 1차 비교 차트/데이터 초안

## 5-1. 1차 초안으로 제시되었던 자료 (6단계 검토 대상 원본)

| 1차 자료 | 내용 (추정) |
| --- | --- |
| 1인가구 10년 증가 추이 | 1인가구 수·비중의 장기 추세 그래프 — 시장 배경용 |
| KB 1인가구 가성비 55.4% | KB경영연구소 「2026 한국 1인가구 보고서」 기반, 1인가구의 소비 성향(실속·가성비 우선 55.4% vs 품질·완성도 우선 16.2%) |
| KREI 편리성 43.1%·비용절감 31.8% | 3단계에서 확인한 간편식 구매 이유 데이터를 4단계 가설(채널 전환)의 근거로 재사용 |
| 무료배달 종료 71.3%·추가 배달비 70.3% | 한국소비자교육지원센터·인하대 조사(전국 배달앱 소비자 n=1,000) — 가격 조건 변화에 따른 실제 이용 행동 변화 |
| 배민 42.1%×59.7%=25.1% 환산 | 3단계의 두 비율(혼자 주문 비중 × 최소주문금액 이탈 비중)을 곱해 만든 파생 수치 |
| 배민 한그릇 10배·11배·13배 | 최소주문금액 폐지 이후 주문 건수·이용자·메뉴 증가 배수 (3단계에서 이미 인용된 수치를 시계열 차트로 재구성) |

## 5-2. 이 단계에서 아직 해결되지 않은 문제 (6단계로 승계)

1차 초안 상태에서는 서로 다른 조사의 표본(1인가구 전용 표본 vs 전체 식품소비자 vs 전체 배달앱 이용자)이 구분 없이 나열되어 있었다. 이 때문에 "1인가구가 정확히 70%가 행동을 바꾼다"처럼 표본이 다른 수치를 하나의 모집단인 것처럼 합성할 위험이 있었다 — 이 문제를 6단계에서 "증거 사슬(evidence chain)" 방식으로 교정한다.

또한 배민 42.1%×59.7% 환산치처럼 표본 수가 공개되지 않은 파생 수치, 그리고 한그릇 10배 증가처럼 서비스 지역·메뉴 확대가 동시에 일어나 순수 가격효과로 보기 어려운 수치가 검증되지 않은 채 섞여 있었다 — 이런 항목의 정제가 [6단계](./06-iterative-refinement.md)의 핵심 작업이다.

## 다음 단계로

5단계의 원본 산출물은 "그럴듯해 보이지만 표본·인과 해석이 검증되지 않은 차트 모음"이었다. 이를 감안해 6단계에서는 각 자료를 유지/제외/강등으로 판정하고, 살아남은 자료만으로 최종 시각화를 재구성한다.
